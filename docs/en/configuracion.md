# Configuration

MyDGX is configured with environment variables read from the `.env` file at the root
of the project. Copy `.env.example` to `.env` and edit only the local file. On the
DGX, the deployment creates `.env` and never overwrites it or copies it from the Mac.

Secrets (`*_API_KEY`, `*_TOKEN`) are only read on the server. They are never
returned to the browser, never written to logs or SQLite, and must not
appear in the code or in Git. The examples use placeholders such as
`YOUR_API_KEY`.

A test (`test_every_setting_is_documented`) fails if a variable is added without
being documented here.

### Changing parameters from Settings

The **Server · .env** card in Settings rewrites only these keys in `.env`
and applies them immediately, except those marked as requiring a restart:
`HF_TOKEN`, `HF_DOWNLOAD_WORKERS`, `MODEL_IMPORT_MAX_GB`, `BENCHMARK_ENABLED`,
`BENCHMARK_AUTO_NEW_MODELS`, `BENCHMARK_REPETITIONS`, `BENCHMARK_QUIET_SECONDS`,
`ASSISTANT_ENABLED`, `ASSISTANT_MODEL`, `ENABLE_PROFILE_AUTOSTART` (restart),
`DEFAULT_PROFILE_ID` (restart), `PROFILE_START_TIMEOUT_SECONDS`,
`MYDGX_SESSION_TTL_MINUTES`, `METRICS_RETENTION_HOURS` and `LOG_RETENTION_DAYS`.

The Hugging Face token is checked with Hugging Face before it is saved and
is never shown again. The file keeps `600` permissions and its comments are
preserved. Authentication, network and privileged-operation keys
(`HOST`, `PORT`, `MYDGX_*_KEY`, `MYDGX_DASHBOARD_PASSWORD`,
`GATEWAY_API_KEY`, `ENABLE_SYSTEM_UPDATES`, `ENABLE_SERVICE_CONTROL`…) can only be
changed by hand in `.env`.

## Server and access

| Variable | Default | Description |
|---|---|---|
| `APP_NAME` | `MyDGX` | Displayed name. |
| `HOST` | `127.0.0.1` | Dashboard address. With a network address, configure a password or API key. |
| `PORT` | `8088` | Dashboard port. |
| `MYDGX_API_KEY` | empty | **Secret.** Key for `/api/*`, header `X-MyDGX-Key`. |
| `MYDGX_DASHBOARD_PASSWORD` | empty | **Secret.** If set, enables web login and an `HttpOnly` session cookie. |
| `MYDGX_SESSION_TTL_MINUTES` | `60` | Absolute expiry of the web session. Clamped between 1 minute and 24 hours. |
| `DUCKDNS_DOMAIN` | empty | DuckDNS subdomain or full name ending in `.duckdns.org`. Accepts several, separated by commas. |
| `DUCKDNS_TOKEN` | empty | **Secret.** DuckDNS token; used only on the DGX. |
| `TRUSTED_HOSTS` | empty | Extra names accepted in the `Host` header (for example `spark.lan`), separated by commas. Loopback and the listening address are already accepted. |
| `DATABASE_PATH` | `./data/mydgx.db` | SQLite database. |
| `DEVICE_VARIANT_OVERRIDE` | empty | Forces the machine identity: `nvidia`, `asus`, `hp`, `lenovo`, `dell` or `generic`. |

To install the hourly DuckDNS updater, set both values
directly in the DGX's `.env` and run from a terminal:

```bash
./start.sh deploy --duckdns --repair --interactive
```

The token is not copied from the Mac and does not appear in the logs. The timer
runs at boot and then roughly every hour.

## Gateway

| Variable | Default | Description |
|---|---|---|
| `GATEWAY_ENABLED` | `true` | Starts the gateway with MyDGX. |
| `GATEWAY_HOST` | `127.0.0.1` | Gateway address. Recommended: localhost only plus SSH tunnel. |
| `GATEWAY_PORT` | `4000` | Gateway port. |
| `GATEWAY_API_KEY` | empty | **Secret.** Required if the gateway listens on the network. |
| `GATEWAY_REQUEST_TIMEOUT_SECONDS` | `600` | Inference timeout. |
| `GATEWAY_MAX_REQUEST_MB` | `32` | Maximum request size. |
| `GATEWAY_LITELLM_PORT` | `4001` | Internal port of the LiteLLM adapter (Responses and Anthropic). |
| `GATEWAY_CORS_ORIGINS` | empty | Allowed browser origins, separated by commas. |

The gateway's web search has no environment variable. It is enabled by
default and is changed in **Settings → Gateway**. OpenCode picks it up on its
next start.

Host, port, timeout and size can also be changed from *Settings*. What is
saved in the interface takes precedence over `.env`.

Gateway error messages (`error.message`) are in English unless the
client asks for Spanish with `X-MyDGX-Language: es` or `Accept-Language: es`. Model
output is never translated.

## Language

| Where | How it is chosen |
|---|---|
| Web interface | Browser language; changed with the ES/EN button in the header or in *Settings*. |
| Dashboard API (`/api/`) | `X-MyDGX-Language` or `Accept-Language` header; Spanish by default. |
| Gateway (`/v1/`) | Same, but English by default. |
| `start.sh`, `deploy.sh`, `serverize` | `MYDGX_LANGUAGE=es` or `en`; if unset, `LC_ALL`, `LC_MESSAGES`, `LANG` or `LANGUAGE`; with `C`/`POSIX`, the macOS language; otherwise, English. `deploy.sh` passes it to the DGX. |

Internal logs (*Logs* and `logs/`) are always stored in Spanish.

## Deployment variables

These are read by `start.sh deploy` on the Mac, not by the backend:

| Variable | Description |
|---|---|
| `OPENWEBUI_VERSION` | Open WebUI version (pinned by default). |
| `SEARXNG_IMAGE` | SearXNG image, pinned by digest. |
| `COMFYUI_REF` | ComfyUI commit. |
| `MYDGX_KNOWN_HOSTS` | File of trusted SSH keys (default `~/.MyDGX/known_hosts`). |
| `MYDGX_SSH_HOST_FINGERPRINT` | Expected DGX fingerprint (`SHA256:...`) for non-interactive deployments. |
| `MYDGX_SSH_ACCEPT_NEW` | `1` accepts a new key without confirmation. Only for ephemeral machines. |
| `MYDGX_HASHCAT_SHA256` | Expected SHA-256 if the hashcat version is changed. |
| `MYDGX_CLAUDE_INSTALLER_SHA256` | SHA-256 of the native Claude Code installer. |
